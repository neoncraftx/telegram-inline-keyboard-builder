# Contributing to Telegram Inline Keyboard Builder

First of all, thank you for considering contributing to **Telegram Inline Keyboard Builder** ❤️

This project aims to become a **framework-agnostic Telegram UI toolkit** that makes inline keyboard creation safer, smarter, and more powerful — no matter which Telegram API or framework you use.

Contributions of all kinds are welcome:
- Bug reports
- Feature requests
- Documentation improvements
- Code contributions
- Tests
- Performance optimizations
- Validation rules / plugins

---

## Before You Start

Please check:

- Existing issues
- Open pull requests
- The project roadmap

If you want to work on a large feature, it is recommended to open an issue first to discuss the implementation.
